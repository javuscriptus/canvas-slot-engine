# Готовый арт

Положите сюда PNG — и сборка возьмёт их вместо сгенерированной графики.
Код игры менять не нужно: имена кадров зафиксированы в манифесте.

```
art/symbols/<ключ>.png   символы барабанов
art/ui/<имя>.png         кнопки, рамка, панели
art/img/<имя>.png        фоны, логотип, баннеры
```

После добавления файлов:

```bash
node tools/assets/build.mjs
```

Скрипт напечатает, сколько ассетов подставлено из этой папки, а сколько
сгенерировано. Версия ассетов в манифесте изменится сама, поэтому у игроков
сбросится кеш.

## Требования к файлам

Символы — квадратный PNG с прозрачностью, сторона не меньше 512 px
(меньше будет мылить на экранах с высокой плотностью). Изображение
масштабируется с сохранением пропорций и вписывается в квадрат.

Фоны — 1920×1080 для ландшафта и 1080×1920 для портрета.

## Имена символов

Ключи берутся из `server/src/math/gameConfig.js` (`SYMBOL_KEYS`) и жёстко
связаны с математикой: id символа в ленте — это индекс в этом списке.
Переименовывать нельзя, можно только заменить картинку.

Текущий список: смотрите вывод `node -e "console.log(require('./server/src/math/gameConfig').SYMBOL_KEYS)"`.

## Имена UI и картинок

Полный список — ключи `frames` в `client/assets/atlas/ui.json`
и ключи `images` в `client/assets/manifest.json`.
